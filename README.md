# Patterns In Chess
Created by Robert Borrell

Based on First Order Induction of Patterns in Chess
by Eduardo Morales, PhD Thesis, Turing Institute 1992.

PAL System
---
This is a modern version of the original PAL System written in SWI-Prolog

Project Goals
---
Rewrite original PAL System into SWI-Prolog
Test and generate examples based on articles
  e.g. KRK, KPK, and KRKN end-games
Add code for game traces
Add tactical motifs to learn:
  - double attack
  - discovered attack
  - pinning
  - deflection
  - decoying
  - interception
  - annihilation of defense
  - space clearance
  - blockade
  - x-ray attack
  - overloading of pieces
  - intermediate move
  - pawn breakthrough
  - passed pawn
  - demolition of pawn structure
  - pursuit
